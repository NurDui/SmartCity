# qadam · прогулки по Астане

Рабочий прототип **первой задачи хакатона**: городской помощник, который подбирает 1–3 места по запросу, району, свободному времени и погоде. Задача CampusPulse в этот проект не входит.

qadam сначала ищет места в локальном каталоге, применяет ограничения и только затем составляет ответ. Для каждого места он объясняет выбор, оценивает время посещения, предлагает действия и показывает источник. При опасной для прогулки погоде приоритет получают помещения. Карта в демо схематичная, а время пешком приблизительное.

## Запуск

Нужен Node.js **22.13 или новее**.

```sh
npm install
npm run dev
```

Откройте адрес, который напечатает сервер. Стандартный адрес локальной разработки: `http://localhost:5173`.

```sh
npm test
npm run check
npm run build
npm run collect:poi
```

Дополнительно `npm run smoke` проверяет API при уже запущенном сервере. `collect:poi` запускает автоматизированное обновление каталога из открытых источников и требует интернет. Сборщик сохраняет происхождение данных и не подставляет вымышленные рейтинги или часы работы вместо отсутствующих значений. Фактический итог последнего сбора: [data/collection-report.json](data/collection-report.json).

## Режим генерации

Без ключа API приложение работает в **шаблонном режиме**: поиск и фильтры настоящие, а объяснения строятся по правилам. Это удобный демонстрационный режим, но он не выполняет генерацию LLM.

Для полного RAG с LLM добавьте серверные переменные окружения и перезапустите приложение:

```env
OPENAI_API_KEY=your_server_side_key
OPENAI_MODEL=gpt-4.1-mini
```

Ключ нельзя помещать в клиентский код или переменные с префиксом `NEXT_PUBLIC_`. Модель можно заменить доступной в вашем аккаунте. При недоступности провайдера демо возвращается к шаблонному ответу и показывает фактический режим.

## Что проверить в демо

1. Выберите район Экспо, зимний сценарий и запрос «Хочу погреться и посмотреть что-нибудь интересное». Проверьте рекомендации помещений и предупреждение о погоде.
2. Переключите летний сценарий и запрос на спокойную прогулку. Сравните результат.
3. Измените лимит времени и интересы. Откройте источник у места и проверьте, что рекомендация ссылается на данные каталога.
4. Разрешите геолокацию только по кнопке или продолжайте с выбранным районом. Сохраните место в избранное.

Режимы «Зима» и «Лето» используют явно обозначенные демонстрационные погодные условия. Режим текущей погоды обращается к Open-Meteo. Доступность внешних сервисов зависит от сети.

## Данные и интеграции

Каталог объединяет автоматизированный снимок открытых геоданных и редакционное обогащение по Visit Astana. Часть координат может быть ориентировочной и маркируется в карточке. Недоступность источников и использованный резервный способ сбора отражает отчет. Рейтинги не выдумываются. Часы отображаются при наличии, но проверка «сейчас открыто» в прототипе не выполняется.

2GIS, Ticketon, kino.kz и sxodim доступны через внешние ссылки для самостоятельного уточнения маршрута, билетов и событий. В прототипе **нет договорных API-интеграций**, покупки билетов и подтвержденной живой афиши.

Открытые геоданные и погода: [OpenStreetMap](https://www.openstreetmap.org/copyright), [Wikidata](https://www.wikidata.org/wiki/Wikidata:Licensing), [Open-Meteo](https://open-meteo.com/en/docs). Конкретные ссылки происхождения хранит каталог. Перед публичным использованием данных проверьте условия и атрибуцию каждого источника.

## Границы прототипа

qadam не гарантирует режим работы, наличие билетов, доступность для колясок, качество воздуха, состояние дорожек или безопасность конкретного перехода. Расстояние по прямой и примерное время ходьбы не учитывают ограждения, мосты и входы в здания. Итоговый путь проверяйте в навигационном сервисе. Подробности и план развития есть в документации.
