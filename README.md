# Seruen · Астана в вашем ритме

Рабочий прототип **только первой задачи хакатона**: городской помощник с поиском по каталогу и опциональной генерацией LLM. При первом входе посетитель отвечает на пять вопросов: настроение, компания, улица или помещение, бюджет на человека и желание поесть. Seruen предлагает 1–3 места с объяснением, временем посещения, действиями и источниками. При опасной погоде приоритет получают помещения.

## Возможности

- Обновленный адаптивный интерфейс, светлая/темная тема и русский, казахский, английский языки. Внешние сюжеты могут оставаться на языке источника.
- Персональные фильтры, избранное и изменение предпочтений. Предпочтения хранятся в браузере; история координат приложением не сохраняется.
- Каталог из 53 мест с поиском и тематическими фильтрами. 37 локальных фотографий с авторством и лицензией, для 16 точек — подписанная иллюстрация. Фото не выдаются за сегодняшние без подтверждения даты съёмки.
- Независимый погодный блок с температурой, ощущаемой температурой, ветром, источником и временем актуальности. При сбое текущие градусы скрываются; демосценарии обозначены отдельно.
- Карта после согласия: Яндекс JavaScript API при `YANDEX_MAPS_JS_API_KEY`, иначе 2GIS MapGL или Leaflet/OpenStreetMap. Масштаб, перемещение, собственные маркеры и слой пробок при наличии данных провайдера. Яндекс использует отдельную проверку балла 0–10, 2GIS — 1–10. Поисковые и платные продукты Яндекса не вызываются.
- Актуальная публичная киноафиша: сгруппированные сеансы, доступные сюжеты, постеры, цены, кинотеатры, подтвержденные ТЦ, расстояния, фильтр кинотеатров и ссылки на источник.
- События на сегодня из официальной публичной афиши Astana.kz: изображения по ссылкам источника, проверка даты и времени. Подборка ограничена подтвержденными площадками.
- Серверные адаптеры согласованных фидов кино, событий и трафика. Договорные API Ticketon/kino.kz пока не подключены; баллы пробок не выдумываются.

## Запуск

Нужен Node.js **22.13 или новее**.

```sh
npm install
npm run dev
```

Откройте адрес из вывода сервера, обычно `http://localhost:5173`. При необходимости скопируйте `.env.example` в локальный файл окружения. На Windows при конфликте npm можно использовать `node "C:/Program Files/nodejs/node_modules/npm/bin/npm-cli.js" run dev`.

```sh
npm test
npm run check
npm run build
npm run smoke
npm run collect:poi
node scripts/collect-events.mjs
node scripts/collect-landmarks.mjs
node scripts/collect-photos.mjs
```

Smoke требует работающего сервера. Сборщики требуют интернет. Отчеты сохраняют происхождение и фактический результат; отсутствующие рейтинги, часы, цены и сведения о ТЦ не выдумываются.

## Подключение данных

Полное руководство с официальными ссылками, форматами фидов, кешем и настройкой ключей: **[docs/live-integrations.md](docs/live-integrations.md)**.

1. **2GIS:** оформите подходящий продукт MapGL/Map Tiles, ограничьте браузерный ключ продуктом, доменом и квотой; установите `TWOGIS_MAPGL_KEY`. Places и Routing оформляются отдельно. Без ключа работает OSM, пробки остаются неизвестными.
2. **Ticketon, kino.kz:** получите согласованный API/фид или партнерский экспорт. Ваш серверный адаптер преобразует данные в `lib/live-types.ts`. Установите `CINEMA_FEED_URL` / `EVENTS_FEED_URL` и соответствующие токены.
3. **Telegram/Instagram:** подключите собственные или разрешенные каналы/профессиональные аккаунты через официальные API. Отдельный сборщик публикует нормализованный фид событий. Произвольный доступ ко всем чатам и аккаунтам не реализован.
4. **Хостинг:** значения окружения задаются в настройках Sites, после изменения требуется развертывание. Секреты нельзя помещать в репозиторий, `NEXT_PUBLIC_*` или `.openai/hosting.json`.

Для Яндекса браузерный ключ хранится в настройках хостинга и передается SDK после согласия. Ограничьте его точным доменом `seruen-astana.connect550439.chatgpt.site` в кабинете Яндекса. Серверный геокодер, его ключ и публичный маршрут остаются выключенными. Подробнее: [карта и лимиты](docs/yandex-integration.md). Проверка совпадений названия: [docs/name-check.md](docs/name-check.md).

Без партнерских фидов доступны публичные адаптеры [Киноафиши](https://kz.kinoafisha.info/astana/movies/) и [Astana.kz](https://astana.kz/ru/events). Это ограниченная подборка, зависящая от доступности и верстки источников. Время загрузки отличается от времени изменения публикации; интерфейс обозначает это. Наличие билетов не гарантируется. Расстояния вычисляются по прямой.

## RAG и ограничения

Seruen сначала ищет и фильтрует каталог, затем составляет ответ по найденным местам. Без `OPENAI_API_KEY` работает обозначенный **шаблонный режим**. С ключом доступен RAG с LLM; `OPENAI_MODEL` задает модель. При ошибке провайдера применяется шаблонный ответ.

Неизвестные цены обозначены. Нулевой бюджет для POI означает явно описанный самостоятельный внешний осмотр без покупок, транспорта и входных билетов. Погода поступает из Open-Meteo; летний и зимний режимы являются подписанными демосценариями. Время ходьбы оценочное. Карта не вычисляет маршрут, входы или переходы; точность маркера показана в карточке.
