# Seruen: карта, LLM и собственный домен

Состояние реализации: 20 октября 2026, только задача 1 хакатона.

## Карта сейчас

Яндекс больше не используется в интерфейсе и его ключ не выдаётся браузеру. MapLibre GL JS 6.15.0 поставляется внутри сборки; фоновый worker собран отдельно и загружается с нашего домена. Карта загружается после согласия. Работают маркеры каталога, поиск точки старта, масштаб, компас, полноэкранный режим, геолокация по кнопке и пешеходный маршрут с поворотами. Выбор точки старта сбрасывает старую рекомендацию. Изменение цели или старта удаляет старый маршрут.

Без дополнительных ключей подложка — стандартные растровые тайлы OpenStreetMap. Она остаётся светлой в тёмном интерфейсе: названия и обозначения не перекрашиваются. Нет 3D-зданий, спутника, сведений о пробках, доступности входов или гарантированно открытых переходов. Для этих функций нужны отдельные данные. Это не навигатор для непрерывного GPS-сопровождения.

`CARTO_BASEMAPS_KEY` подключает светлую/тёмную CARTO-подложку. Ключ теперь обязателен: [получение](https://carto.com/basemaps/apikey/), [условия](https://carto.com/legal/basemap-terms/). Аккаунт и согласие с условиями оформляет владелец. Действует общий месячный лимит по аккаунту; бесплатность не означает неограниченное использование. Включите Referer-ограничение на реальный домен, счётчики и уведомления в кабинете. Публичный браузерный ключ не является серверным секретом. Мы не можем гарантировать общую квоту CARTO по браузерным запросам без дополнительных настроек провайдера.

[Политика OSM-тайлов](https://operations.osmfoundation.org/policies/tiles/): видимая атрибуция, обычное интерактивное использование, браузерное кеширование, без выгрузки города и офлайн-предзагрузки. Сервер не обещает SLA; для роста аудитории нужен договорной провайдер либо свои тайлы. Подложка не переводится автоматически вместе с языком интерфейса: надписи запечены в растровые изображения.

## Поиск и маршруты

Локальный поиск по каталогу работает без внешних запросов. Внешний поиск Nominatim вызывается **только отправкой формы**, не при наборе символов, без фонового обхода города. В запросе ограничены Казахстан, рамка Астаны и пять результатов. Пользователь выбирает результат сам. Не следует вводить личные адреса и конфиденциальные сведения.

**Обязательная политика Nominatim:** https://operations.osmfoundation.org/policies/nominatim/. Максимум 1 запрос/сек на всё приложение, идентифицирующий User-Agent/Referer, кеширование, атрибуция, запрет автодополнения и массового сбора. Владелец явно выбрал Nominatim в запросе на реализацию; публичный сервис подходит только небольшой аудитории и не даёт гарантии доступности. Его можно отключить `NOMINATIM_ENABLED=false` или переключить `NOMINATIM_SEARCH_URL` на свой совместимый HTTPS endpoint без изменения кода. URL задаётся только владельцем на сервере, не посетителем.

Пешеходный граф — [OSRM/FOSSGIS](https://routing.openstreetmap.de/about.html), endpoint `routed-foot`. Слово `driving` внутри формата URL OSRM не означает автомобильный профиль: профиль определяет отдельный сервер `routed-foot`. Реальные geometry/distance/duration/steps берутся из ответа сервера. По прямой линия не рисуется. Если пути нет или привязка к дорожке дальше 500 м, точный маршрут не показывается. `OSRM_ENABLED=false` отключает провайдера. Геометрия проверяется на размер, диапазон координат и разумные значения. Координаты маршрута не сохраняются приложением; FOSSGIS сообщает о собственных журналах запросов. Время не учитывает ветер, светофоры, ремонт, ступени, временные ограждения и доступность входа. Проверяйте переходы. Есть ссылка на исправление OSM и запасной переход в 2ГИС.

Серверные ограничения D1 общие для всех экземпляров Worker и посетителей: по одному зарезервированному запросу каждые 2 секунды к каждому источнику, максимум 1 000 попыток за скользящие 24 часа для Nominatim и 1 000 для маршрутов. Резервирование выполняется одним атомарным SQL statement. Отправка разрешена в течение 500 мс, начиная до обращения к БД; просроченная бронь остаётся потраченной. Ошибка, 429 или редирект не вызывают повторную отправку. При отсутствии D1 запрос блокируется. Хранятся только название сервиса, случайный ID и время, без IP и маршрутов. История резервов удаляется после 48 часов при последующих обращениях. Результаты поиска публичных мест кешируются на 24 часа; вместо текста запроса — SHA-256. Это не анонимизация по строгому определению: распространённый поисковый запрос можно угадать по хешу. Записи с истёкшим сроком не выдаются, удаляются при последующих успешных/неуспешных сетевых обращениях.

Важно: оценка времени на карточке рекомендации всё ещё предварительная (расстояние по прямой ×1,3 / 75 м в минуту). Подробный маршрут вычисляется отдельно после нажатия кнопки. Он может оказаться длиннее допустимого бюджета времени — надо выбрать другое место. Массовые фоновые запросы маршрутов для всех карточек специально не выполняются.

## Что работает в RAG

Сейчас в опубликованной конфигурации нет ключа LLM. Работает поиск по 53 POI, BM25 с синонимами, предпочтения мини-опроса и фильтры погоды, бюджета, помещения, еды, времени и расстояния. Из найденных записей шаблоны составляют 1–3 альтернативы. Это режим `template`, который виден и на странице, и в `/api/health`.

Генеративная ветка реализована, но без ключа не выполняется. Сервер передаёт LLM найденные записи, разрешённые идентификаторы и обезличенные предпочтения. Точные координаты и исходный свободный текст посетителя не передаются. Модель предлагает объяснение и действия; название, координаты, время и цена остаются серверными данными. Проверяются схема, 1–3 уникальных ID из найденных кандидатов, язык, длина и ряд неподтверждённых утверждений. Проверка эвристическая, не доказывает истинность каждого предложения. Не прошедший ответ, недоступный провайдер или квота возвращают шаблон, а не выдуманные места.

Подготовлены серверные совместимые провайдеры `openai`, `groq`, `gemini`, `openrouter`. Нужны секрет `LLM_API_KEY`, `LLM_PROVIDER` и `LLM_MODEL`. Выберите модель с поддержкой JSON Schema / structured outputs. Для старой OpenAI-конфигурации сохраняются `OPENAI_API_KEY`/`OPENAI_MODEL`. Ни один новый провайдер без ключа не активирован. Запросы имеют таймаут 10 с и ограничение ответа 1 000 токенов; общий D1-предел — 100 попыток генерации за скользящие сутки и интервал 2 с. Это ограничивает расход, но не заменяет финансовые настройки и квоты аккаунта провайдера. Ключ используется только этим проектом, если хотите сопоставлять лимиты проекта с лимитами аккаунта.

Постоянная доступность помощника означает вызов модели по запросу посетителя через сервер — собственный включённый компьютер не нужен. Непрерывный агент, который ищет события и меняет контент, — другая система: планировщик → разрешённые источники → проверка дат, города, ссылок, дублей и прав на медиа → LLM для краткого описания → запись в БД → публикация данных. Он должен менять проверенные записи, а не исполнять текст из сайтов как команды или переписывать исходники. Нужны журналы изменений, отмена публикации и бюджет. Сейчас такой сборщик по расписанию не включён. Погода/афиша обновляются по запросу и таймерам открытой страницы; это не круглосуточный обход всех источников.

## Можно ли читать сайты вместо API

Уже подключены ограниченные публичные адаптеры афиши с указанием источника и времени нашей проверки. Если страница недоступна или дату нельзя подтвердить, событие/сеанс не выдумывается. Публичная доступность не даёт автоматически права на массовое копирование описаний, фотографий или базы. Нужны разрешённый способ получения, соблюдение условий/robots, проверка лицензии и короткое собственное изложение фактов. robots.txt сам по себе не является лицензией. Платные разделы, вход по аккаунту, CAPTCHA и антибот не обходятся. Изменение HTML ломает парсер, сведения о билетах могут устареть. Надёжное масштабирование: партнёрский API/фид, фид самого организатора, разрешённые Telegram-ботом публикации владельца канала.

## Фото и проверка каталога

Временный герой — локально сохранённое фото Ботанического сада, Людмила Помазанова / milapom, Pixabay, опубликовано 24 июля 2020. Дата съёмки неизвестна, на сайте стоит «архивное фото». [Карточка](https://pixabay.com/photos/kazakhstan-astana-botanical-garden-5434504/), [лицензия](https://pixabay.com/service/license-summary/), полный учёт в `public/images/astana-pixabay-garden.credit.json`. Pixabay не обеспечивает фото, снятое сегодня. Автоматический поиск фото через их API требует ключа, кеша ответов на 24 часа; постоянный hotlink запрещён. [API](https://pixabay.com/api/docs/).

Проверять факты можно независимо по официальным источникам; владелец не обязан лично подтверждать каждую карточку. Сведения без подтверждения остаются неизвестными. Проверка одной страницы не подтверждает все 53 места и сегодняшнюю работу каждого входа. Результаты текущей проверки перечислены в `data/poi-verification-2026-10-20.json`. Для постоянной актуальности нужен разрешённый сборщик с отдельными датами проверки фактов, а для физически закрытых входов — данные самой площадки.

## Собственный домен

Сайт уже опубликован в обычном интернете. Удалить `connect…chatgpt.site` из адреса можно **без переноса**: Sites поддерживает собственные домены и HTTPS. Сначала зарегистрируйте доступное доменное имя на своё имя у регистратора. Затем добавьте точный hostname в Sites; сервис вернёт необходимые CNAME/A и проверочные DNS-записи. Внесите именно возвращённые значения у регистратора, дождитесь активного статуса DNS и сертификата. На текущем проекте собственных доменов пока нет. Домен не выбран, не куплен и не подключён.

Альтернатива — ваш Cloudflare Workers аккаунт + D1: это наиболее близко текущему стеку. Нужны исходники, сборка, D1, SQL-миграции, серверные переменные, Workers deployment и привязка домена. На Vercel/обычный хостинг нельзя просто загрузить HTML: сайт содержит серверные маршруты и Cloudflare bindings, их потребуется адаптировать. Статическая выгрузка потеряет поиск/маршруты/RAG/погоду. Для `.kz` перед выбором хостинга отдельно проверьте действующие требования регистратора и законодательства к размещению; не считайте зарубежный edge автоматически подходящим.

После выбора домена: canonical, sitemap/robots, Search Console, ссылки на домен, обновление Referer-разрешений ключей. Видимость по адресу и появление в поисковой выдаче — разные вещи; индексация не мгновенна.

## Бесплатные варианты для тестирования

Проверены официальные страницы на 20.10.2026; условия могут измениться.

| Задача | Вариант | Что учитывать |
|---|---|---|
| Карта | MapLibre + OSM для небольшой аудитории | Библиотека бесплатна, общественные серверы имеют политику нагрузки и не дают SLA |
| CARTO | Бесплатная квота с отдельным ключом | Текущие месячные квоты и коммерческие условия в кабинете; это не недельный trial |
| Геоданные/маршруты | [Geoapify Free](https://www.geoapify.com/pricing/) | 3 000 кредитов/день, без карты; разные операции тратят разное число кредитов |
| Маршруты | [GraphHopper Free](https://www.graphhopper.com/pricing/) | Некоммерческое использование, ограниченные профили и кредиты |
| LLM | [Groq Free Plan](https://console.groq.com/docs/rate-limits) | Лимиты по модели/минутам/дню, проверьте JSON Schema и качество RU/KK |
| LLM | [Gemini API Free tier](https://ai.google.dev/gemini-api/docs/pricing) | Только доступные региону/модели квоты; условия обработки данных бесплатного уровня отличаются |
| LLM | [OpenRouter :free](https://openrouter.ai/docs/guides/routing/model-variants/free) | Меньшие лимиты и меняющаяся доступность моделей; передача выбранному провайдеру |
| Фото | [Pixabay API](https://pixabay.com/api/docs/) | Ключ, кеш 24 ч, без массовых скачиваний и постоянного hotlink |
