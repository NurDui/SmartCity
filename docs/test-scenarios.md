# Сценарии приемки Seruen

Сценарии проверяют наблюдаемое поведение. Они не являются заявлением, что каждый ручной тест уже выполнен. Автоматические проверки запускаются через `npm test`. Демонстрационные погодные режимы дают воспроизводимые условия.

Для каждого сценария фиксируйте дату, версию каталога, язык, параметры опроса, фактический режим генерации, полученные POI и результат. Для афиши фиксируйте дату `Asia/Qyzylorda`, источник и время проверки. Проверяйте итоговые карточки, а не только текст ответа модели.

| 2 | Летний режим, «спокойно погулять на свежем воздухе» | Открытые места участвуют в подборе. Для каждой рекомендации есть причина, примерная длительность и действия |
| 3 | Тот же запрос и район, уменьшить свободное время | Подбор учитывает новый лимит. Место, для которого очевидно не хватает времени с учетом принятой модели, не должно занимать верхнюю позицию без объяснения |
| 4 | Запрос «уютное место с историей» и старт на Правом берегу | Исторические или культурные теги повышают релевантность подходящих записей. Система не выдумывает историю заведения |

## Техническая приемка

После установки зависимостей выполните `npm test`, `npm run check` и `npm run build`. При запущенном сервере выполните `npm run smoke`. Для отчета публичных событий доступна команда `node --experimental-strip-types scripts/collect-events.mjs`. В ручной проверке пройдите как минимум сценарии 1, 2, 5, 7, 9, 16, 18, 20–22, 25–29. Вызов реального LLM и MapGL с действующими ключами проверяйте отдельно: успешная сборка и тестовые ответы их не подтверждают.

Автоматические тесты проверяют границы погодных и пользовательских фильтров, бюджет, языки, разрешенные POI для LLM, fallback, даты и формат афиши, безопасность ссылок, провайдерские баллы и отсутствие секретов в конфигурации. Число и результат последнего запуска фиксируйте по фактическому выводу команд, поскольку набор расширяется.

В ходе подготовки текущей ревизии 18 октября 2026 года реальный локальный HTTP POST `/api/discover` вернул 23 сеанса и одно событие на эту дату. Это свидетельство конкретной проверки, количество публикаций меняется. Тесты LLM и фидов используют также подставные ответы и ошибки сети. Реальный оплачиваемый вызов LLM и полноценный MapGL с ключом не подтверждаются этими тестами.

Презентация и видео `qadam-*` в `output/` относятся к предыдущей ревизии. Они не являются записью прохождения этих расширенных сценариев Seruen.
