## Откуда координаты, цены и изображения

- Проведены 12 адресных запросов Geoapify. Десять совпали по улице и номеру дома. Два ошибочных результата — Ailand на другой улице и Sandyq на другой улице с тем же номером — отклонены. Для них использованы точки, опубликованные Visit Astana. Исходные адреса и результаты оставлены в `data/venue-geocode-requests.json` и `data/venue-geocode-results.json`.
- Все точки обозначают здание или комплекс, а не проверенный вход. Атрибуция Geoapify / OpenStreetMap и ссылка на источник координат сохранены в каждой соответствующей записи.
- Неизвестные цены и рейтинги — `null`. Нулевой бюджет не должен превращать такие места в «бесплатные». Время на посещение является редакционной оценкой. Часы показаны только там, где их явно сообщает источник, с просьбой уточнить перед визитом.
- Коммерческие фотографии новых заведений не скопированы. Пока нет лицензированной фотографии, интерфейс использует предусмотренную иллюстрацию. Владелец может позже добавить собственные или разрешённые фотографии с авторством и лицензией через `data/poi-photos.json`.
- Набор воспроизводится `node scripts/apply-curated-venues.mjs`. Это небольшая проверенная редакционная подборка. Автоматический исходный сбор открытых POI остаётся отдельным механизмом `npm run collect:poi`; подборка не выдаётся за результат широкого автоматического парсинга.

## Роль 2GIS

2GIS используется для перехода к карточке места и дополнительной проверки пользователем. Наша база не копируется из справочника 2GIS. [Лицензионное соглашение 2GIS](https://law.2gis.kz/licensing-agreement/), в частности пункты 6.1.2 и 6.1.4, ограничивает извлечение данных и создание производных справочников. Массовый сбор, рейтинги и отзывы из 2GIS не подключены. Для такого использования нужен подходящий договор/API с правами на хранение и показ данных. Ключ JavaScript-карты сам по себе таких прав не даёт.

## Что теперь автоматически делает афиша

При запросе сайта сервер проверяет ограниченный набор публичных городских источников: Astana.kz и Visit Astana. D1 хранит общую копию по типу данных, дате Астаны и языку на 15 минут. Координаты пользователя, IP и текст его запроса в этот кэш не попадают. Расстояние рассчитывается отдельно для каждого запроса, если адрес площадки действительно известен.

Обновление требует посещения сайта. Это не фоновый обход всего Интернета и не автономный браузер LLM. Groq не получает возможность произвольно открывать Instagram, Telegram или редактировать код сайта. Сервер собирает афишу по фиксированным правилам; LLM отдельно формулирует рекомендации по найденным записям каталога.

Один сбор ограничен городскими страницами: Astana.kz — robots.txt, страница афиши и максимум четыре карточки с датой сегодня; Visit Astana — robots.txt и публичная страница афиши. Установлены таймауты, пределы размера ответа, запрет перехода по редиректам и краткий интервал ожидания после ошибки. Защищённые входом страницы и скрытые API не обходятся. Разрешение в robots.txt не является лицензией на фотографии; у публичных афиш сохраняются ссылки на издателя и организатора, постеры не скачиваются в нашу медиатеку. Для долгосрочного коммерческого использования материалов желательно оформить разрешённый фид и права на изображения.

Нельзя подменять дату извлечения данных датой обновления самим издателем: `retrievedAt` заполнено, `sourceUpdatedAt` неизвестно. При каждом чтении кэша повторно исключаются уже прошедшие сеансы и окончившиеся события.

Проверка 20.10.2026 в 13:35 по времени Астаны нашла две многодневные афиши Visit Astana:

- «Затерянный мир Великой степи…» — 1–31 октября.
- «Открытие новой выставки — BETAŞAR!» — 8–31 октября.

Это опубликованные периоды, включающие сегодня; они не доказывают открытие площадки именно в текущий час. Точные часы, адреса и цены в доступных карточках не указаны, поэтому интерфейс явно просит уточнить их у организатора и не показывает выдуманное расстояние. Astana.kz в этой проверке не вернул подходящих точных событий. Результат проверки — `data/events-collection-report.json`.

Проверочный запуск: `node --experimental-strip-types scripts/collect-events.mjs`. Тесты `tests/discovery-cache.test.mjs` проверяют валидность дат, запрет чужих ссылок, отсутствие выдуманных координат, исключение просроченных данных, единственный сбор при конкурентных запросах и отказ без внешних запросов при недоступном D1.
