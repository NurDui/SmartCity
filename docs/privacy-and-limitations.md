# Приватность, достоверность и ограничения

Этот документ относится только к первой задаче хакатона, городскому помощнику Seruen. Он описывает текущий прототип с опросом предпочтений, интерактивной картой и актуальной афишей. Настройка источников подробно описана в [руководстве интеграций](live-integrations.md).

## Локация и хранение

Точная геолокация запрашивается только после явного действия пользователя и разрешения браузера. Доступен сценарий без геолокации: выбрать район или стартовую точку. Отказ в разрешении не должен блокировать основной подбор.

Для поиска серверу нужны координаты выбранной стартовой точки. Приложение не создает историю перемещений и не записывает точные координаты или свободный текст запроса в собственную базу либо localStorage. В браузере сохраняются ID избранных мест, язык, тема и профиль опроса: интерес, размер компании, предпочтение помещения или улицы, бюджет на человека и желание поесть. Эти предпочтения можно изменить через опрос, а полностью удалить локальное сохранение можно через очистку данных сайта в браузере.

Пользовательский интерфейс передает параметры подборов через POST. Это не помещает точные координаты в URL обычного access-log. Для совместимости у `/api/discover` остается диагностический GET с координатами в строке запроса, без отдельной авторизации администратора. При его использовании хостинг может записать URL. Для эксплуатации нужно ограничить диагностический доступ и настроить удаление координат из журналов, отключить запись тел запросов и определить сроки хранения IP и метаданных. Отсутствие собственной базы локаций не означает отсутствие обработки хостингом.

Для текущей погоды сервер передает Open-Meteo координаты, округленные до двух знаков после запятой. Точная точка устройства провайдеру погоды не отправляется. Это уменьшает точность, но не делает такой запрос полностью анонимным.

При подключении LLM сервер передает разрешенные предпочтения и контекст найденных публичных мест. В контекст входят язык, размер компании, выбор пространства и еды, а бюджет передается общим стилем. Исходный текст запроса и точные координаты пользователя обрабатывает сервер приложения, они не передаются внешней LLM. При облачном развертывании обработка не остается полностью на устройстве. Перед промышленным запуском нужно сверить фактический payload, политику провайдера, регион обработки и юридические основания. При переходе по внешним ссылкам начинают действовать правила соответствующего сервиса.

Даже без точных координат набор найденных мест может косвенно указывать на район поиска. Такой обмен не является полной анонимизацией. Внешней модели следует передавать только поля, необходимые для формулировки идеи посещения.

## Карта, афиша и внешние изображения

Внешние SDK и тайлы загружаются после отдельного согласия на карту. Приоритет провайдеров: Яндекс → 2GIS → Leaflet/OpenStreetMap; резерв выбирается при отсутствии ключа или отказе SDK. Выбранный поставщик получает IP-адрес и область просмотра, в которую может входить точка старта. При переходе на резерв сетевые обращения получает также его поставщик. Согласие не хранится между посещениями страницы. Закрытие карты прекращает ее отображение, но не отменяет уже переданные сетевые запросы. Картографическая атрибуция должна оставаться видимой.

Карта Яндекса настроена через браузерный ключ, настоящий доступ и пробки на домене еще требуют приемки. Используются собственные POI и явные элементы масштаба, полного экрана и пробок. Геолокация SDK, поиск, саджест, панорамы и маршрутные запросы Яндекса не включены. Определение координат по разрешению браузера выполняет само приложение. Подготовленный серверный геокодер остается выключенным: D1 не привязана, публичного маршрута нет, ответы Яндекса не добавляются в каталог и RAG. Настройка ключа не подтверждает соответствие бесплатной лицензии; применимость условий описана отдельно в [разборе рисков](yandex-free-risks.md).

Поставщикам киноафиши и событий сервер не передает координаты устройства. Он получает общий набор публикаций Астаны, а расстояния считает сам. Кеш не хранит точку пользователя. Интерфейс отображает постеры и фотографии по внешним ссылкам, поэтому браузер может обращаться к CDN источника независимо от согласия на карту. Для более строгой приватности нужен согласованный медиапрокси.

Ключи LLM, Bearer-токены согласованных фидов и секреты подготовленного геокодера остаются на сервере. Предназначенные для браузера ключи Яндекса и MapGL возвращает `/api/runtime-config`. `YANDEX_MAPS_JS_API_KEY` установлен в секретах хостинга, в репозитории значения нет; после выдачи клиенту этот ключ виден посетителю по назначению. Такие ключи следует ограничить точным разрешенным доменом, продуктом и квотой. Нельзя использовать вместо них неограниченный серверный ключ. Ограничитель будущего серверного геокодера не ограничивает загрузки браузерной JS-карты.

Telegram и Instagram не подключены к пользовательским аккаунтам автоматически. Для получения публикаций нужен отдельный коннектор с разрешением владельца канала или профессионального аккаунта, нормализующий данные в фид событий. Прямого чтения произвольных чужих аккаунтов и отправки сообщений в прототипе нет.

## Как ограничивается недостоверная информация

Каталог хранит происхождение POI. Ответ ссылается на конкретные записи и их источники. Отсутствующие часы и рейтинг остаются неизвестными. Генератор не должен выводить из отсутствия данных, что место открыто, бесплатно, безопасно или доступно без ступеней.

Поиск и погодные ограничения работают до генерации. LLM получает только найденные места. Сервер проверяет ID, число и структуру рекомендаций, длину текста и ряд запрещенных фактических обещаний. Сгенерированные идеи имеют отдельную маркировку. Эта эвристическая проверка не доказывает фактическую корректность всего текста. Названия, координаты, время и внешние ссылки карточек происходят из каталога. При сбое LLM приложение переключается на шаблонный ответ и показывает режим.

Реальная проверка источника выявила устаревший пример из исходной идеи проекта: [QazExpoCongress](https://qazexpocongress.kz/ru/nur-alem/) сообщает о завершении приема посетителей в Музее энергии будущего с декабря 2024 года. На той же странице указан действующий в здании alem.ai и Музей Сингулярности. Каталог использует актуальное название, а исторические описания старого музея не служат подтверждением текущего доступа. Проверено 18 октября 2026 года.

Инструкции внутри пользовательского запроса и описаний мест не могут отменять ограничения. Сценарии такого вмешательства включены в приемку.

Сеансы и события поступают из внешних данных отдельно от LLM. Для фидов проверяются сегодняшняя дата в `Asia/Qyzylorda`, свежесть обновления, координаты и структура. Публичные адаптеры принимают явную дату сеанса на странице и сохраняют источник. Время нашей загрузки не является временем последнего изменения публикации издателем. При неизвестном времени издателя это явно указано. Источник может ошибаться или поздно обновить отмену, поэтому «загружено сейчас» не гарантирует наличие билетов.

Изображение берется из публикации источника и может быть афишей или рекламным постером. Оно не доказывает фактическое проведение мероприятия. Ссылка на файл не передает права на его повторное использование. Цена с признаком «от» является нижней границей, а неизвестная цена не считается нулевой.

## Погода и безопасность

Текущую модельную погоду предоставляет Open-Meteo. Сервер проверяет численные значения и возраст данных до двух часов. При ошибке или устаревшем ответе он включает консервативный зимний сценарий с явным предупреждением. Зимний и летний режимы служат для воспроизводимого демо и обозначаются как симуляция. Модель комфорта упрощена и не оценивает здоровье, одежду, локальный гололед или ветровые коридоры между зданиями.

В мороз и при сильном ветре RAG-подбор ограничивает открытые локации, даже если предпочтение опроса было «на улице». Это подсказка по планированию, а не гарантия безопасности дороги до помещения. Не следует автоматически советовать самокат на морозе, при сильном ветре или без знания безопасной инфраструктуры. Блок афиши показывает публикации и не подтверждает погодную пригодность пути к событию.

Балл пробок появляется только из настоящего подключенного источника. Он не выводится из цвета дорог и не заменяется произвольным числом. Яндекс JS API использует балл 0–10 после инициализации провайдера, где ноль допустим; 2GIS MapGL и текущий серверный фид используют отдельный контракт 1–10. Слой и число зависят от ключа, покрытия, свежести и доступности SDK. Реальное получение балла Яндекса для Астаны с установленным ключом еще требует проверки. Дорожная загруженность не является оценкой безопасности пешей прогулки.

## Существенные ограничения демо

| Область | Что это означает для пользователя |
| --- | --- |
| Часы и рейтинг | Могут отсутствовать или устареть. Нужно открыть первоисточник перед визитом. Фильтра «сейчас открыто» нет |
| Координаты | Часть редакционных записей содержит ориентировочную точку, что отмечено в карточке |
| Карта и пеший маршрут | Карта географическая, но маркер может быть ориентировочным. Расстояния и оценка ходьбы не учитывают препятствия и входы |
| Время посещения | Приблизительная оценка. Рекомендации являются альтернативами, а не полным маршрутом |
| Доступность | Нет подтвержденного аудита для колясок, детских колясок и особых потребностей |
| События и билеты | Есть текущие публикации, но покрытие неполное. Загрузка страницы не подтверждает свободные места, отсутствие отмены или окончательную цену |
| Кафе и бюджеты | Отсутствие цены не означает бесплатное посещение. При нулевом бюджете редакционное «снаружи» не обещает бесплатный вход внутрь |
| Компания | Число участников влияет на подбор, но не подтверждает вместимость, наличие столика и возможность брони |
| Языки | Системные тексты и рекомендации локализованы. Исходные названия и сюжеты афиши могут оставаться на языке публикации. Казахский интерфейс SDK Яндекса не обещается: `kk_KZ` не заявлен в списке JS API 2.1 |
| Пробки | Без свежего провайдерского балла число недоступно. Оно не описывает пешеходный путь |
| Актуальность | Автоматический сбор не заменяет проверку закрытий и временных изменений |
| LLM | Без API-ключа доступен шаблонный режим. При ключе возможны ошибки модели |
| Сеть | Геоданные, погода и провайдер модели могут быть недоступны |

## Что нужно перед публичным запуском

Провести проверку точек и ссылок на выборке. Настроить журнал изменений каталога, время последнего успешного обновления и правила удаления устаревших записей. Проверить разрешения и лицензии источников. Ввести ограничение частоты запросов, наблюдение за ошибками и тестирование с пользователями. Для партнерских рекомендаций явно отмечать коммерческий интерес и не менять погодные ограничения ради рекламы.

Презентация и видео с именами `qadam-*` в `output/` относятся к предыдущей ревизии. Они не заменяют это описание текущих ограничений Seruen.
