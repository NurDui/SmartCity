# Яндекс Карты: условия бесплатной интеграции в Seruen

Проверено: **18 октября 2026 года**. Это разбор опубликованных условий и их применения к архитектуре Seruen, а не подтверждение допуска проекта со стороны Яндекса. Тарифы и редакции документов нужно повторно проверять перед запуском.

## Вывод для проекта

Бесплатное открытое демо может соответствовать условию доступа, но этого недостаточно для подтверждения права на бесплатное использование всех API. Seruen рекомендует городские места, поэтому широкая оговорка о схожих картографических сервисах требует отдельной оценки. До выбора бесплатной лицензии разумно письменно описать Яндексу функции проекта и уточнить применимую редакцию условий.

**Каталог и RAG остаются независимыми от Яндекса.** Seruen использует самостоятельно собранные открытые геоданные, редакционные описания и ссылки на источники. Собственные POI не становятся данными Яндекса только из-за отображения маркерами на его карте. Размещение собственных данных поверх карты прямо предусмотрено, в частности, для Tiles API в пункте 6.5.1 RU-условий. Это не снимает остальные ограничения выбранного API и не подтверждает применимость бесплатной лицензии к Seruen в целом.

Правило интеграции Seruen: ответы API Яндекса не записываются в каталог, историю запросов, файлы, векторный индекс или базу RAG. Данные Яндекса не используются как источник описаний, рейтингов, цен или координат для независимого каталога.

## Доступ и назначение сервиса

- Пункт 4.1.1 требует бесплатного открытого доступа неограниченного круга лиц. Обычная общедоступная регистрация допустима; платный доступ и обязательное предоставление данных удостоверения личности относятся к ограничениям доступа.
- Документация бесплатного использования также исключает разработку решения с API для перепродажи. Возможная будущая коммерциализация требует повторной оценки конкретной модели, а не предположения, что бесплатный прототип автоматически разрешает платный продукт.
- Первый пункт 5.1.4 текущих RU-условий запрещает создание на основе сервисов продуктов с аналогичным или схожим функциональным и целевым назначением с Яндекс Картами и другими сервисами Яндекса. Поиск мест, карта и персональные рекомендации Seruen могут попадать в широкое прочтение этой нормы. Это интерпретация риска; окончательная классификация проекта Яндексом неизвестна.
- Пункт 2.4 предусматривает письменное согласование иных условий либо использование на соответствующих коммерческих условиях. Общего требования отдельно согласовывать каждый небольшой бесплатный проект нет. Пункт 4.2 прямо требует предварительного обращения при суточной аудитории свыше 100 000 пользователей.

Источники: [RU-условия, разделы 2, 4 и 5](https://yandex.ru/legal/maps_api/ru/); [условия бесплатного использования, пункты 1–2](https://yandex.ru/dev/commercial/doc/ru/).

На дату проверки RU-документ на yandex.ru имеет дату публикации **01.09.2026**, а русскоязычный документ на yandex.kz — **16.08.2024**. В последнем запрета аналогичных сервисов в указанной формулировке нет. При этом англоязычная страница yandex.kz содержит такой запрет в пункте 5.1.4. Нельзя считать отсутствие нормы в старой казахстанской RU-версии гарантированным исключением для Seruen. В обращении следует уточнить редакцию, применимую к владельцу проекта и его резидентству.

Источники: [RU](https://yandex.ru/legal/maps_api/ru/), [KZ на русском](https://yandex.kz/legal/maps_api/ru/), [KZ на английском](https://yandex.kz/legal/maps_api/en/).

## Данные, ранжирование и кеш

- RU-пункт 5.1.5 и KZ-пункт 5.1.4 ограничивают сохранение, обработку и изменение данных, полученных через сервисы. Исключение для временного служебного кеша до **30 дней** связано только с улучшением работы предусмотренных сервисами функций. Это не общее разрешение хранить любую выгрузку 30 дней.
- Бесплатная документация запрещает перенос результатов геокодера в собственную БД и изменение ранжирования поисковых результатов. Для сценариев хранения она указывает расширенную коммерческую лицензию; обычная платная лицензия не должна считаться автоматическим разрешением на любое повторное использование.
- Полученные от Яндекса описания, координаты, результаты поиска и маршруты нельзя направлять в embeddings, RAG-корпус или независимое повторное ранжирование без отдельно предоставленных прав. Вычисление рекомендаций Seruen производится по собственному каталогу.
- Геокодирование связано с отображением на карте Яндекса: RU-пункт 6.6.1 и KZ-пункт 6.1.1. Результаты геокодера нельзя переносить на OSM/2GIS. Аналогичные ограничения для маршрутов предусмотрены соответствующими пунктами о маршрутизации. При переключении провайдера используются собственные POI, а не результаты API Яндекса.

Источники: [RU, пункты 5.1.2, 5.1.5, 6.2 и 6.6.1](https://yandex.ru/legal/maps_api/ru/); [KZ, пункты 5.1.4 и 6.1.1–6.1.3](https://yandex.kz/legal/maps_api/ru/); [бесплатная документация, пункт 2](https://yandex.ru/dev/commercial/doc/ru/).

## Карта, оформление и согласие посетителя

Логотип, копирайты, ссылка на условия и кнопка открытия карты должны оставаться видимыми. Нельзя перекрывать их своими карточками, погодой, плашкой пробок или мобильной навигацией. Для мобильного приложения предусмотрена ссылка на условия в разделе о приложении. Документация бесплатного использования запрещает размещение скриншотов карт; для статичных материалов следует использовать разрешённый для этого инструмент, а не снимать карту в презентацию или экспортировать её как свой фон.

Пункт 8.1 предусматривает автоматическую обработку Яндексом IP-адресов, идентификаторов устройств и геоданных посетителей и возлагает на владельца сайта получение соответствующих согласий. В Seruen SDK должен загружаться только после явного информированного выбора пользователя. Текст согласия должен называть Яндекс и объяснять передачу данных; отсутствие собственного хранения локации не означает отсутствия обработки провайдером.

Источники: [RU, пункты 4.1.3 и 8.1](https://yandex.ru/legal/maps_api/ru/); [KZ, пункты 4.1.3 и 8.1](https://yandex.kz/legal/maps_api/ru/); [бесплатная документация, пункты 3 и 6](https://yandex.ru/dev/commercial/doc/ru/).

## Продукты, реклама и доступность

Бесплатный показ карты не означает бесплатного неограниченного поиска, геокодирования или маршрутизации. Продукты и лимиты подключаются отдельно. Для Tiles API опубликовано отдельное исключение, допускающее коммерческие и закрытые системы; его нельзя автоматически распространять на другие API. Отслеживание людей или транспорта и диспетчеризация имеют отдельные коммерческие ограничения по пункту 5.1.3; разовая добровольная точка старта не должна превращаться в такой мониторинг.

Пункт 4.7 допускает рекламу провайдера. На странице тарифов отдельно описан платный вариант отключения рекламы. Пункты 4.6, 6.7, 9.1 и 10.1 предусматривают приостановки, ограничения и отсутствие гарантии бесперебойности. Seruen должен сохранять полезный список мест и внешние ссылки при недоступной карте. Переключение карты не даёт права переносить между провайдерами данные Яндекса.

Источники: [RU-условия](https://yandex.ru/legal/maps_api/ru/); [раздельное подключение продуктов](https://yandex.ru/maps-api/docs/news/new-billing/free-usage.html); [тарифы для KZ и бесплатные обращения к карте](https://yandex.kz/dev/tariffs/doc/ru/jsapi/prices/).
