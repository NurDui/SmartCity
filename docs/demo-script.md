# Запись демо и сдача

## Подготовленный видеообзор

В комплект входит [qadam-demo.mp4](../output/video/qadam-demo.mp4): 72 секунды, подписи на экране, без голоса. Видео собрано из реальных снимков работающего интерфейса. Это последовательный обзор экранов, а не непрерывная запись пользовательских действий. Для живой записи с голосовым комментарием используйте сценарий ниже.

Скрипт повторной сборки: `scripts/make-demo-video.py`. Для него нужны Python, Pillow, imageio-ffmpeg и шесть свежих снимков интерфейса в `tmp/demo/`, названных согласно списку `STEPS` в скрипте. Временная папка может отсутствовать в архиве исходников. Эти зависимости не входят в требования веб-приложения. После пересборки проверьте фактический MP4 и соответствие его подписей текущему интерфейсу.

## Видео около 90 секунд

Подготовьте локально запущенное приложение, чистую вкладку браузера и запись экрана. Закройте страницы с ключами и персональными данными. Для воспроизводимости используйте район вместо точной геолокации. Перед записью проверьте, что в кадре виден фактический режим генерации.

| Время | Действие на экране | Реплика |
| --- | --- | --- |
| 0:00–0:10 | Главный экран qadam | «Это первая задача хакатона: помощник по прогулкам в Астане. Он учитывает место, время и погоду» |
| 0:10–0:25 | Выбрать Экспо, зимний режим, 60–90 минут. Запросить теплую прогулку | «Начнем с воспроизводимого сценария: минус 25. Ограничения применяются до составления ответа» |
| 0:25–0:45 | Показать результаты, причину, длительность и действия | «В каждой рекомендации есть конкретное место, объяснение и план посещения. Здесь виден режим ответа» |
| 0:45–0:58 | Открыть сведения об источнике и ссылку 2GIS | «Факты берутся из каталога. Часы и реальный путь нужно уточнить в первоисточнике и навигаторе» |
| 0:58–1:12 | Переключить летний сценарий и интерес «на свежем воздухе» | «В другом погодном контексте меняется допустимый набор мест. Демо-погода помечена явно» |
| 1:12–1:22 | Сохранить место в избранное, показать выбор района | «Геолокация добровольная. В браузере мы храним только ID избранных мест» |
| 1:22–1:30 | Вернуться к результатам | «Код, сценарии и ограничения входят в комплект. Следующий шаг: проверенный каталог и пешеходная маршрутизация» |

Если ключ LLM не настроен, произнесите: «Сейчас включен шаблонный режим, поиск и погодные фильтры работают. Серверный ключ включает генерацию LLM». Не называйте шаблонную генерацию выполненным вызовом модели.

## Перед загрузкой

- `npm test`, `npm run check` и `npm run build` завершились успешно, результаты записаны командой.
- В архиве или репозитории есть исходники, lockfile, README и документация. Исключены `.env`, API-ключи, `node_modules`, временные файлы и журналы.
- В презентации открываются русские шрифты. PDF содержит те же 8 слайдов.
- Видеозапись показывает реальную работу, а режим погоды и генерации читаемы.
- Нет лица, домашнего адреса и точной текущей локации участника без необходимости.
- Ссылки на источники и внешние сервисы открываются.

## Сдача на YouTube

Загрузку выполняет участник команды в своем аккаунте. Можно использовать подготовленный обзор MP4 или непрерывную запись по сценарию. Укажите в названии «qadam · ИИ-помощник по прогулкам в Астане». В описании добавьте ссылку на репозиторий или архив, отметьте формат видео и шаблонный или LLM-режим записи, кратко назовите ограничения. Выберите доступ, который допускают правила хакатона, и проверьте просмотр ссылки без входа в аккаунт автора. Затем передайте жюри ссылку на видео, код, презентацию и документ ограничений.

Этот проект не публикует видео и не создает репозиторий от имени команды. Такие ссылки появляются после фактической загрузки.
