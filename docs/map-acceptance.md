# Проверка обновления Seruen Astana

18 октября 2026 года. Сайт: https://seruen-astana.connect550439.chatgpt.site/.

- Существующий проект Sites переименован без создания дубликата; публичный адрес обновлён.
- Ключ JS API хранится в секретах хостинга. В репозитории, архиве исходников и этом отчёте ключ отсутствует. Браузер получает его по назначению для SDK; это не серверный ключ геокодера.
- На опубликованном сайте после согласия отрисовались карта Астаны, собственные маркеры, улицы, обязательные элементы Яндекса и слой пробок. Геокодер, поисковые API, маршрутизация и панорамы не подключены.
- **Ограничение приёмки:** SDK сообщил `Invalid API key`. Отрисовка не доказывает валидность ключа. Свежий числовой балл пробок не получен. Доступ к кабинету требует входа владельца.
- В кабинете нужно проверить подключение JavaScript API, активацию связи продукта с ключом и домен `seruen-astana.connect550439.chatgpt.site` без схемы и пути. После изменения ограничений Яндекс указывает ожидание до 15 минут. Серверные IP-ограничения нельзя подменять IP компьютера разработчика для браузерного ключа.
- Локальная проверка экранов 390×844 и 1440×1000: горизонтального переполнения нет, основной текст 16 px, вспомогательный минимум 14 px. Собственные подписи карты увеличены; обязательные элементы провайдера не изменялись.
- Подтверждены анимации появления, перехода вопросов и карточек; при уменьшении движения они отключаются. Основное содержимое доступно без поддержки анимаций прокрутки.
- TypeScript, сборка и 73 теста прошли, включая отмену загрузки SDK, смену локалей, нулевой балл и свежесть пробок. Тесты не подтверждают действительность внешнего ключа.

Названия проверены отдельно: [name-check.md](name-check.md). Найден существующий Telegram-помощник Seruen AI с похожим назначением. Уникальность бренда не подтверждена.

Официальные пояснения: [ограничения ключа](https://yandex.ru/maps-api/docs/js-api/limit.html), [получение и активация](https://yandex.ru/dev/jsapi-v2-1/doc/ru/), [причины неработающего ключа](https://yandex.ru/maps-api/docs/developer/index.html).
